# Project brief: Fault-aware physics-based canine gait (patellar luxation)

Working title: *Clinically parameterized physics-based simulation of canine gait: can joint-limit constraints alone reproduce compensatory patterns in patellar luxation?*

## Research questions
- RQ1. If only the stifle (knee) extension limit is lowered to grade-specific clinical values, and no compensation is coded, does an optimized trot show increased hip and hock (tarsal) ROM like the clinical data?
- RQ2. If not (or only partly), what is missing? Separate physical constraint from behavioral compensation (e.g. load avoidance) by ablation.
- RQ3 (extension). From joint trajectories alone, can we estimate which joint is limited and by how much? (small forward-to-inverse step; same pipeline can be applied to a Go2 robot knee limit)

## Contributions
1. Clinical-grade-parameterized canine gait simulator (open source).
2. Quantitative validation against measured ROM, with analysis of mismatch.
3. Constraint -> adaptation -> estimation pipeline, generalized to robot joint faults.

## Scope
- Core (thesis): dm_control Dog (fallback: simplified MJCF dog with hip/stifle/hock per leg), sagittal leg DOFs, knee extension limit per grade, CMA-ES gait optimization (joint amplitude/offset/phase free; objective = speed tracking + stability + torque), ROM comparison with clinical table, sweep + sensitivity, ablations.
- Extension: joint-limit estimation (regression), Go2 generalization, Leo video comparison, Unity render.
- Out: muscle actuation, video->physics inversion, 3D pose reconstruction, classifier, RL (graduate work), frontal-plane indices (Q-angle).

## Data caveats
- Clinical data: primary source Chayatup et al., The Veterinary Journal 313 (2025) 106369 (7 control vs 10 Grade III Chihuahuas, 3.1 kg, trot 1.11 m/s, 2D sagittal). Only Grade 0 and Grade 3 are measured; Grade 1, 2, 4 (Notion table) are interpolated and must be labelled as such. Do not mix AROM and PROM. Validation targets are the per-joint extension/flexion windows (MEA/MFA), not only ROM: stifle [121.8,167.1] -> [96.9,125.1], hock MEA up, hip MFA down. Details: `docs/research_notes.md` section 4, `configs/impairment/patella.yaml`.
- Speed: equal-Froude scaling from the 3.12 kg Chihuahua at 1.11 m/s to the 10.24 kg Dog gives 1.35 m/s.
- Method guard-rail: the first optimisation exploited the cost (forelimb-only shuffle). Gait-level realism terms (duty factor, load split, height) are generic and used for every grade; the kinematic calibration to control dogs is used for the healthy baseline only.
- Leo: 7 kg mixed breed, normal. Film side view, static camera, >=60 fps, steady trot, ~10 clips; measure shoulder height and limb segment lengths.
- YouTube PL videos: qualitative comparison only, record URL in data/real/sources.csv, do not redistribute.
